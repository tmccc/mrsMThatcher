Structured log format
---------------------
Final regular image selections now emit one INFO line:

REGULAR_IMAGE_SELECTED source=<original|generated> basename=<image basename> score=<final score> origin_quote_hash=<64hex-or-empty> origin_quote_match=<true|false> origin_quote_boost=<number>

Example log lines
-----------------
Original image:
REGULAR_IMAGE_SELECTED source=original basename=t44.jpg score=12.5 origin_quote_hash= origin_quote_match=false origin_quote_boost=0.0

Generated image for its originating quote:
REGULAR_IMAGE_SELECTED source=generated basename=tg_aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa.png score=18.0 origin_quote_hash=aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa origin_quote_match=true origin_quote_boost=4.0

Generated image for another quote:
REGULAR_IMAGE_SELECTED source=generated basename=tg_bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb.png score=16.5 origin_quote_hash=bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb origin_quote_match=false origin_quote_boost=0.0

Selector metadata
-----------------
Selected image records now expose:
- image_source: original or generated
- origin_quote_hash: None for originals, 64-hex hash for valid tg_<hash>.png generated images
- origin_quote_match: true only when selected quote hash equals the generated image origin hash
- origin_quote_boost: configured boost only for origin matches; otherwise 0.0

Digest semantics
----------------
- original + generated = total regular image selections
- generated origin matches + generated cross-quote selections = generated selections
- older logs without REGULAR_IMAGE_SELECTED continue to render normally; the new section is omitted
- malformed new-style lines are ignored rather than crashing digest generation
